Lesson Planning Agent

Version 3 · More specific learning activities · Rule-based single-agent prototype

Describe your lesson

Use an observable objective (e.g. compare, explain, justify). If you have restrictions, mention them in the materials field.

Optional activity constraints

These are hard scheduling constraints. When the activity time leaves too little room for opening, explanation and assessment, the agent requests teacher review.

AWAITING INPUT

Agent decision

The agent will choose whether to clarify, generate, or request teacher review.

This application uses predefined JavaScript rules and instructional templates. It does not call an LLM at runtime, check external facts, access student records, or guarantee learning outcomes. Its topic-specific examples are hypothetical; teachers must verify subject accuracy and adapt activities to their learners.
